# Homebrew Tap

Official Homebrew tap for [daftAI2026](https://github.com/daftAI2026) CLI tools.

## Available Formulae

- **[gay](https://github.com/daftAI2026/gay-cli)** — Zero-overhead cross-platform CLI trampoline for `agy`
- **[incodex](https://github.com/daftAI2026/incodex)** — Incognito toggle for the Codex desktop app

## Installation

```bash
brew install daftAI2026/tap/gay
brew install daftAI2026/tap/incodex
```

## Updating

```bash
brew update
brew upgrade gay
brew upgrade incodex
```

## Uninstalling

```bash
brew uninstall gay
brew uninstall incodex
brew untap daftAI2026/tap
```
