# Homebrew Tap

Personal Homebrew tap for [Incodex](https://github.com/daftAI2026/incodex).

## Installation

```bash
brew tap daftAI2026/tap
brew install incodex
```

This only installs the CLI (`incodex` / `inc`). Patching Codex still needs `incodex install`.

## Updating

```bash
brew update
brew upgrade incodex
```

## Uninstalling

```bash
brew uninstall incodex
brew untap daftAI2026/tap
```
